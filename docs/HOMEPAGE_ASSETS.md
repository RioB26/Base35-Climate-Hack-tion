# Homepage illustrations

Generated with the built-in OpenAI imagegen tool on 4 October 2026. No CLI fallback or additional runtime package was used. Generated PNGs were encoded as WebP at quality 0.86 without changing their composition. All project assets are bundled locally by Vite.

These are conceptual illustrations, not photographs of the five landfills or measured satellite data. The hero depicts collection infrastructure and a generator; the wind comparison explains a possible signal. Text labels are rendered in HTML to remain readable and accessible on mobile. Decorative foliage is generated with a transparent background and is hidden from assistive technology.
